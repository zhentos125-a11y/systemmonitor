Ты — Senior Java разработчик плагинов для Minecraft (Paper 1.21.11).
Тебе нужно написать плагин SmartMonitor v2.0 с расширенной функциональностью.
Проект должен быть полным, компилируемым, без внешних зависимостей (кроме SQLite JDBC, которая встроена через shade).

## ОБЩЕЕ ОПИСАНИЕ
Плагин `system.f1xal.monitor` — умный мониторинг сервера с историей, GUI, ролями, самодиагностикой.
Ты должен добавить (сбор TPS, памяти, игроков, чанков, SQLite, GUI, роли, асинхронный сбор).
Ты должен **добавить** три новых модуля:
1. Профилировщик реального времени (CPU по плагинам/мирам/биомам).
2. Внутриигровые графики (таблички / MapView).
3. Самодиагностика с автоматическими действиями.

Все новые модули должны быть интегрированы в GUI, работать асинхронно и не вызывать просадок TPS.

## ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ
- Paper 1.21.11, API версии 1.21.
- Java 17.
- Сборка Maven с maven-shade-plugin (SQLite JDBC внутри).
- Не использовать плагины-библиотеки (guilib и т.п.), только Bukkit API и Paper API.
- Исторические данные — SQLite (файл `metrics.db` в папке плагина).
- Ролевая модель: `smartmonitor.admin`, `smartmonitor.developer`, `smartmonitor.moderator`.
- Асинхронный сбор, буферизация, flush раз в 50 секунд.
- GUI на стандартных инвентарях (54 слота), обновление по таймеру.

## НОВЫЕ МОДУЛИ (подробно)

### 1. Профилировщик реального времени (Profiler)
- Замер **времени выполнения каждого плагина** за тик (через `PluginManager.getPlugins()` + обёртки `ListenerPriority.MONITOR`).
- Метрики: `cpu_ms` на плагин, `% от TPS`, `вызовов/тик`.
- Хранение в памяти (кольцевой буфер 600 точек = 10 минут).
- Вкладка в GUI: «Плагины» — топ-10 самых прожорливых.
- Команды: `/monitor profiler [page]`, `/monitor profiler reset`.
- Важно: не добавляет задержек, использует `System.nanoTime()` с семплированием раз в 2 тика.

### 2. Внутриигровые графики (In‑Game Graphs)
- **Табличка** (Sign) с графиком TPS/памяти за последние 5 минут.
- **Карта** (MapView) — мини‑график TPS (0–20) с цветовой шкалой.
- Обновление каждую секунду (через `BukkitRunnable` async).
- API для добавления своих серий: `GraphAPI.registerSeries("myplugin:tps", ...)`.
- Права: `smartmonitor.graphs.sign`, `smartmonitor.graphs.map`.
- При установке таблички/карты — автоматически привязываются к серверу.

### 3. Самодиагностика с действиями (Smart Actions)
- **Правила** (в конфиге):
  - `tps < 14.5` > 3 мин → `/spark tps` (если есть) + уведомление.
  - `memory.used > 80%` → `/gc` (если есть) + предупреждение.
  - `players > 50` → включить `clear-lag` (если есть).
  - `chunk-load > 500` → `diff` подозрительных чанков.
- **Действия** — выполнение команд от имени консоли, отправка сообщения игроку/дискорду.
- Лог действий в `actions.log`.
- Вкладка «Действия» — история и ручное применение.
- Отключение/включение правил в GUI.
